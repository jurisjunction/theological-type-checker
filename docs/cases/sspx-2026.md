# TTC-CASE-SSPX(7)

## NAME

**sspx** — schism and the Society of St Pius X, 1988–2026

## SYNOPSIS

```
ttc-check sspx lattice [asof_2018] [recourse_decided_2026] [note_as_revocation] ...
```

## DESCRIPTION

"Is the SSPX in schism?" is several questions of two types, and public
argument usually answers one with evidence for the other:

- *How are the acts classified, and where does the Society stand?* This is
  theology, on the authority graph.
- *Who has incurred what, what is declared, which sacraments are valid?*
  This is law, in the canon layer.

The pair is ordered. The classification of each act comes first, and the
law follows it, branch by branch.

Evaluated as of 10 October 2026. No outcome of the Society's recourse had
been reported.

## RESULTS

### Theology

| ID | Result |
| --- | --- |
| SX1–SX3 | 1988 act schismatic; excommunication in force in 1990, remitted in 2009. |
| SX6, SX7 | 2018, "Society in schism?": open. Every "no" is an interview. |
| SX8 | Schism classified on dissent from *Dignitatis humanae*: category error (c. 752 / c. 1365, not c. 751 / c. 1364). |
| SX9 | Adherence inferred from attendance: violation. The DDF's own procedure agrees. |
| SX10 | 2026 act and the Society's schism: settled, on an act-based ground. |

### Law

| ID | Result |
| --- | --- |
| SX11 | Six bishops presumed incurred under c. 1387 (a co-consecrator consecrates: Pius XII, *Episcopalis consecrationis*, 1944). Under c. 1364 where the act is classified as schismatic. Declaration suspended (c. 1353). |
| SX12 | Recourse decided: declaration effective. A missing hearing is a ground for recourse, not a void (c. 124 §2). Disputed fact; computed both ways. |
| SX13 | Approved in forma specifica (hypothetical): no recourse (c. 333 §3). |
| SX14 | The 2009 remission does not reach 2026. |
| SX15 | On the record, the 2016 grant stands. Absolution by an undeclared priest is valid, and licit on a just-cause request (c. 1335 §2). The note is contradicted. |
| SX16 | Papal revocation (hypothetical): later absolutions invalid, each attempt a c. 1379 delict. Earlier ones untouched. The dying absolved (c. 976). Common error supplies (c. 144). |
| SX17 | The note read as revoking: ineffective (c. 135 §2). |
| SX18 | The note read as declaring the clergy: collective declaration, a violation. |
| SX19 | "It was public, so no hearing": violation. c. 1717 §1 dispenses the investigation, never c. 1720 n. 1. |
| SX20 | A declared bishop absolving after effect: invalid (c. 1331 §2 n. 2), and a delict. |
| SX21 | Marriage without delegation: invalid. With delegation: valid. |
| SX22 | c. 751 read as a state: no c. 1364; c. 1387 still reaches Fellay. |
| SX23 | Lattice: faculties stand; sort unchanged. |

### Pair

| ID | Result |
| --- | --- |
| PR1 | Where the act is classified schismatic, c. 1364 applies; where not, only c. 1387. |
| PR2 | Uncoupled, the law applies c. 1364 against its own premise: violation. |

## SWITCHES

| Part | Effect |
| --- | --- |
| `recourse_decided_2026` | The declaration takes effect. |
| `recourse_upheld_2026` | The declaration is annulled; the presumption stands. |
| `decree_papally_approved` | No suspension. |
| `note_as_revocation` (+ `note_papally_approved`) | Ineffective (or, if approved, effective) revocation. |
| `c751_state_reading` | No c. 1364. |
| `hyp_delegation`, `edge_acts` | Delegated marriage; the dying; common error. |

All but the first are hypothetical.

The first version put the juridical questions on the authority graph and
weighed canonists against a dicastery. That was wrong (cc. 16, 18, 19). The
canon layer replaced it, and the faculty result reversed.
